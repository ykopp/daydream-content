# Daydream content channel

This is a release-only repository for Daydream's signed content packages.

- `stable.json` is the current pointer fetched by the App.
- Immutable ZIP files live in GitHub Releases.
- `rights-ledger.json` carries the public provenance and license records for the active package.

It intentionally excludes candidate media, local-only files, review evidence, private contracts, and signing keys. Third-party media retains its own license; this repository does not grant a blanket license over it.
